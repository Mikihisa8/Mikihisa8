Real-time Object Detection and Semantic Mapping on CPU-Powered Mobile Robot

Mikihisa Ishino, Ryuto Ishibashi, Zhenling Su, Lin Meng

Raspberry Pi 4B のような CPU のみの移動ロボット上で、int8 量子化した YOLOv10 を ROS2・SLAM と統合。単眼カメラの検出結果を地図上に投影し、リアルタイムなセマンティックマッピングを実現。

CEUR Workshop Proceedings Vol-4082

Lightweight YOLOX-Based Object Detection with Structural Pruning for Edge Device Deployment

Mikihisa Ishino, Lin Meng

YOLOX のバックボーンに、BatchNorm のスケール係数（γ）に基づく反復的な構造プルーニングを適用。CPU のみのエッジデバイスでも、精度を保ちながら計算量を大きく削減。リサイクル向けの独自データセット（ペットボトル・缶・ガラス瓶）で有効性を検証。
